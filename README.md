Mahendra Medics
Mahendra Medics is a web-based e-commerce application developed for a local medical store to enable customers to browse and place orders for medicines online.

Overview:-
This project focuses on building a simple and functional online ordering system for a retail pharmacy. It allows users to view available medicines, add them to a cart, and place orders without online payment integration.

Features
Browse medicines with product details
Add items to cart
Place orders with customer information
Basic order management
Simple and user-friendly interface
Tech Stack
Frontend: ASP.NET Web Forms
Backend: C# (.NET Framework)
Database: Microsoft SQL Server
Project Structure
UI built using ASP.NET Web Forms
Backend logic handled in C#
Database designed for products, customers, and orders
How It Works
User browses available medicines
Adds required items to cart
Provides basic details (name, contact, address)
Places order
Order is stored in the database for processing by the store

Notes:-
This project does not include a payment gateway(UPI Id was provided and the user upload the transactionId (manually verified by agent) and then the order used to be placed.)
Designed for offline order handling by the store
Built as part of real-world requirement simulation
